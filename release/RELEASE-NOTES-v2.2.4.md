## DLSS5 ReShade AIO v2.2.4

### 32-bit live Optical Flow controls

- Optical Flow can now be enabled or disabled live from the 32-bit ReShade menu.
- Optical Flow working resolution changes now apply live in 32-bit games.
- Both controls use the x64 addon's safe reconfiguration path, avoiding a game or host restart.

This release retains the v2.2.3 low-latency Optical Flow defaults and all existing 32-bit and 64-bit functionality.
